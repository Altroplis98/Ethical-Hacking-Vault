# VNC (5900)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Remote desktop protocol — **often no auth or weak password**. Frequently installed by admins for convenience and left exposed. Direct GUI access if you get in. The VNC password is a fixed 8 chars — quick to brute force. RealVNC has had auth bypass CVEs historically. **Common attack vectors:** no-auth check, brute force (only 8-char passwords matter), credential stuffing, session capture via PCAP.

## Enumerate

```bash
nmap -sV -sC -p 5900 $IP
nmap --script vnc-info -p 5900 $IP
```

## Connect

```bash
vncviewer $IP:5900
vncviewer $IP::5900   # note double colon for port
```

## Brute-force

```bash
hydra -P passwords.txt vnc://$IP -V
nxc vnc $IP -p passwords.txt
nmap --script vnc-brute -p 5900 $IP
```

## Crack VNC password file

```bash
# VNC password file is usually at:
# ~/.vnc/passwd (Linux)
# Registry on Windows

# Decrypt with vncpwd
vncpwd passwd_file
```

## Common findings

- No authentication required → direct desktop access
- Weak password (often 8 chars max due to DES limitation)
- Cleartext protocol (unless SSH tunneled)
