# IMAP / IMAPS (143 / 993)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Interactive mail access. Same credential risk as POP3, but IMAP leaves mail on the server — useful for **long-term intel collection** without tipping off the user. Password spraying is common here because lockout policies on mail servers are often laxer than on domain accounts. **Common attack vectors:** password spraying, brute force, credential stuffing, OAuth token abuse on cloud mail.

## Connect

```bash
telnet $IP 143
openssl s_client -connect $IP:993   # IMAPS
```

## Commands

```text
a1 LOGIN user password
a2 LIST "" "*"              # list mailboxes
a3 SELECT INBOX             # select inbox
a4 SEARCH ALL               # list all messages
a5 FETCH 1 BODY[]           # read message 1
a6 LOGOUT
```

## Brute-force

```bash
hydra -l user -P passwords.txt imap://$IP
hydra -l user -P passwords.txt -s 993 -S $IP imap
```

## Enumerate

```bash
nmap -sV -sC -p 143,993 $IP
nmap --script imap-capabilities -p 143 $IP
```
