# DNS (53)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Every network has it. Check for **zone transfers (AXFR)** first — they hand you a full internal network map in one query. Also a covert channel for **DNS tunneling** (dnscat2, iodine) and data exfiltration when other egress is blocked. UDP and TCP both matter — TCP 53 is used for AXFR and large responses. **Common attack vectors:** zone transfer (AXFR), DNS cache poisoning, DNS tunneling, subdomain enumeration, amplification (if resolver is open).

## Enumerate

```bash
nmap -sV -sC -p 53 $IP
nmap -sU -sV -p 53 $IP   # UDP
fierce --domain zonetransfer.me
dig @$IP -x $IP                    # reverse lookup -> leaks domain suffix
dig @$IP version.bind CHAOS TXT    # BIND version -> CVE + OS mapping
```

> [!tip] No domain name yet? Chain it: `dig @$IP -x $IP` (PTR) OR `dig @$IP <domain> SOA` -> get zone -> `dig AXFR @$IP <domain>`. Always use `@$IP` to hit the target directly. See [[02 - DNS Recon Basics]].

## Zone transfer

```bash
dig AXFR @$IP domain.com
host -t axfr domain.com $IP
dnsrecon -d domain.com -t axfr -n $IP
```

## DNS queries

```bash
dig @$IP domain.com ANY
dig @$IP domain.com A
dig @$IP domain.com MX
dig @$IP domain.com NS
dig @$IP domain.com TXT
dig @$IP -x $IP   # reverse lookup
```

## Subdomain brute-force

```bash
dnsrecon -d domain.com -t brt -D /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -n $IP
gobuster dns -d domain.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -r $IP:53
```

## DNS cache snooping

```bash
dnsrecon -t snoop -n $IP -D /usr/share/seclists/Discovery/DNS/common-dns-queries.txt
```
