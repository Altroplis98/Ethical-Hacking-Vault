# MongoDB (27017)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

NoSQL database. **No authentication by default** in older versions (< 3.6 listened on 0.0.0.0 with no auth out of the box). Frequently still internet-exposed with no auth. Yields full database dumps instantly if open. NoSQL injection from the app layer is the second-most-common path. **Common attack vectors:** no-auth database dump, NoSQL injection from app layer, credential harvesting from stored data, Server-Side JS injection (legacy).

## Connect

```bash
mongosh --host $IP
mongosh --host $IP -u admin -p 'pass' --authenticationDatabase admin
```

## Enumerate

```bash
nmap -sV -sC -p 27017 $IP
nmap --script mongodb-* -p 27017 $IP
```

## Key commands

```javascript
show dbs
use database_name
show collections
db.collection.find().pretty()
db.users.find({}, {username:1, password:1})
```

## Common findings

- No authentication → full database access
- Default credentials
- Exposed to internet without firewall
