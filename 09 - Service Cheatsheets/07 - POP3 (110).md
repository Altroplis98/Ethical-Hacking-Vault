# POP3 (110)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Mail retrieval. Cleartext on 110, encrypted on 995. Users reuse passwords — cracking mail creds can cascade to VPN, SSO, and domain accounts. Once authenticated, you read every message in the mailbox (intel goldmine for further engagement). **Common attack vectors:** brute force, credential stuffing, cleartext sniffing (port 110), harvesting email content for further intel.

## Connect

```bash
telnet $IP 110
# or with SSL
openssl s_client -connect $IP:995
```

## Commands

```text
USER username
PASS password
LIST            # list messages
RETR 1          # retrieve message 1
DELE 1          # delete message 1
QUIT
```

## Brute-force

```bash
hydra -l user -P passwords.txt pop3://$IP
smtp-user-enum -M RCPT -U userlist.txt -D inlanefreight.htb -t 10.129.203.7
```

## Enumerate

```bash
nmap -sV -sC -p 110,995 $IP
nmap --script pop3-capabilities -p 110 $IP
```
