# Redis (6379)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

In-memory data store. Frequently runs with **no authentication** in dev / cache deployments. You can write SSH keys to `.ssh/authorized_keys` via Redis `CONFIG SET` + `SAVE`, achieving unauthenticated RCE if Redis runs as root or any user with a home directory you can write to. Also useful: write a webshell into the webroot via `CONFIG SET dir`. **Common attack vectors:** unauthenticated access, SSH key injection for RCE, config file write for cron-based RCE, web shell drop into webroot, data exfiltration, SSRF pivoting (Redis listens on the internal NIC and trusts localhost).
