# SNMP (161 UDP)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Network device management. Default community strings (`public`, `private`) are still **extremely common**. v1/v2c is cleartext and unauthenticated with default strings. A successful walk yields device configs, routing tables, ARP caches, interface info, and sometimes credentials embedded in the running config. On printers and routers this is your fastest intel path. **Common attack vectors:** community string brute force, MIB walking for device info, config extraction, v1/v2c sniffing.

## Enumerate community strings

```bash
onesixtyone $IP -c /usr/share/seclists/Discovery/SNMP/common-snmp-community-strings.txt
nmap -sU -sV -p 161 --script snmp-brute $IP
```

## Walk the MIB tree

```bash
snmpwalk -v 2c -c public $IP
snmp-check $IP
```

## High-value OIDs

```bash
snmpwalk -v 2c -c public $IP 1.3.6.1.4.1.77.1.2.25    # Users
snmpwalk -v 2c -c public $IP 1.3.6.1.2.1.25.4.2.1.2    # Processes
snmpwalk -v 2c -c public $IP 1.3.6.1.2.1.6.13.1.3      # TCP ports
snmpwalk -v 2c -c public $IP 1.3.6.1.2.1.25.6.3.1.2    # Installed software
```
