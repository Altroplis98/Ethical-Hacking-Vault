# mdk4

802.11 denial-of-service and stress-testing framework. More attack modes than aireplay-ng deauth, including beacon flooding, auth DoS, and EAPOL attacks.

[[10 - Wireless/00 - README|Folder index]]

## Install / verify

```bash
which mdk4
sudo apt install mdk4
```

> [!danger] Legal
> All mdk4 attacks are denial-of-service. Use only in authorized engagements on isolated test networks.

## Attack modes

| Mode | Flag | Description |
| --- | --- | --- |
| Beacon flood | `b` | Flood fake SSIDs |
| Authentication DoS | `a` | Overwhelm AP with auth requests |
| Deauthentication | `d` | Mass deauth (more aggressive than aireplay-ng) |
| EAPOL start flood | `e` | Flood 802.1X auth starts |
| Michael countermeasure | `m` | Trigger TKIP shutdown |

## Beacon flood (confusion / IDS test)

```bash
sudo mdk4 wlan0mon b -c 6
# Floods channel 6 with random fake SSIDs
# -f ssids.txt to use custom names
# -a to use random BSSID for each
```

## Mass deauth

```bash
# Deauth everything on the channel
sudo mdk4 wlan0mon d

# Deauth specific target
sudo mdk4 wlan0mon d -B <BSSID>

# Whitelist your own AP
echo "<YOUR_BSSID>" > whitelist.txt
sudo mdk4 wlan0mon d -w whitelist.txt
```

## Authentication flood

```bash
sudo mdk4 wlan0mon a -a <BSSID>
# Floods AP with auth requests until it crashes or stops accepting clients
```

## When to use mdk4 vs aireplay-ng

| Scenario | Tool |
| --- | --- |
| Targeted deauth for handshake capture | `aireplay-ng -0` |
| Mass disruption / stress test | `mdk4 d` |
| Beacon flood for IDS testing | `mdk4 b` |
| Auth DoS to test AP resilience | `mdk4 a` |
